# SkillBridge website (React + Tailwind CSS + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Edit text, stats and contact details in `src/data/content.js`.

Routes: `/`, `/about`, `/initiatives`, `/portfolio`, `/contact`.
When hosting, send all paths to `index.html` (`public/_redirects` for Netlify and `vercel.json` for Vercel are included).
